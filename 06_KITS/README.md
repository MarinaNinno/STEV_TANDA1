# Kits de evaluación STEV

Esta carpeta contiene los kits de evaluación para aplicar el protocolo STEV.

## Archivo principal

- `Kit_Evaluacion_STEV_v1.0.md`: kit final para aplicar el instrumento con los 10 ejercicios.

## Versiones históricas

En la carpeta `historico/` están los kits de las versiones anteriores:

- `Kit_Evaluacion_STEV_v0.3.md`
- `Kit_Evaluacion_STEV_v0.4.md`
- `Kit_Evaluacion_STEV_v0.5.md`
- `Kit_Evaluacion_STEV_v0.6.md`
- `Kit_Evaluacion_STEV_v0.6_Etapa5.md`

## Cómo usarlo

1. Enviar al evaluador el kit final (`Kit_Evaluacion_STEV_v1.0.md`).
2. El evaluador debe aplicar el Codebook v1.0 a los 10 ejercicios.
3. Registrar los resultados en la plantilla de `09_recoleccion_externa/`.

## Relación con otras carpetas

- `01_codebook/`: contiene el instrumento que el kit ayuda a aplicar.
- `04_corpus/`: contiene los ejercicios evaluados.
- `09_recoleccion_externa/`: contiene el formato de entrega.
