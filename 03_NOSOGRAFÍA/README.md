# Nosografía STEV

Esta carpeta contiene el catálogo de códigos y la descripción del protocolo tricapa.

## Archivos

- `Nosografia_STEV_v0.md`: catálogo de 62 códigos organizados en 19 familias.
- `Protocolo_STEV_tricapa.md`: descripción general del protocolo STEV.

## Qué contiene la nosografía

La nosografía define los códigos que se usan en las tres capas:

- **L1 — Causa:** códigos interpretativos sobre el origen técnico-ontológico del fallo.
- **L2 — Manifestación:** códigos deterministas sobre cómo aparece el fallo en el texto.
- **L3 — Impacto:** códigos sobre el efecto cognitivo que genera la respuesta.

## Cómo usarla

1. Leer primero `Protocolo_STEV_tricapa.md`.
2. Usar `Nosografia_STEV_v0.md` como catálogo de consulta.
3. Para aplicar el instrumento, usar el kit final en `06_kits/`.
4. Para entender cambios de códigos, revisar `02_decision_log/`.
