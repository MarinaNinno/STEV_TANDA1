# Análisis transversal

Esta carpeta contiene los análisis del corpus original y de la consolidación inicial.

## Archivos

- `Capa1_AnalisisParalelo.md`: análisis paralelo de la primera capa.
- `Capa2_AnalisisTransversal.md`: análisis transversal del corpus original.

## Para qué sirven

Estos documentos explican cómo se detectaron los problemas iniciales del corpus:

- Códigos no homologados.
- Movimientos de capa incorrectos.
- Fronteras críticas no resueltas.
- Casos mal aplicados.

Fueron la base para la homologación y para las primeras iteraciones del Codebook.

## Cómo leerlos

Se recomienda leerlos después de `00_cierre/Proyecto_STEV_Cierre.md` y antes de `01_codebook/historico/`.
