# Decision Log STEV

Esta carpeta contiene el registro de decisiones estructurales del proyecto STEV.

## Archivo principal

- `DecisionLog_STEV.md`: registro de 67 decisiones documentadas.

## Qué registra

Cada decisión incluye:

- Fecha.
- Versión del Codebook o del dataset.
- Cambio realizado.
- Motivo del cambio.
- Evidencia que lo justificó.
- Resultado esperado.

## Cómo leerlo

El Decision Log está pensado para auditoría. No es un resumen del proyecto: es la trazabilidad de por qué el instrumento llegó a ser como es.

Se recomienda leerlo después del `Proyecto_STEV_Cierre.md` y antes de replicar análisis.

## Relación con otras carpetas

- `01_codebook/`: contiene las versiones del instrumento que el Decision Log explica.
- `05_pilotos/`: contiene los resultados que motivaron varias decisiones.
- `00_cierre/`: contiene el documento maestro del proyecto.
