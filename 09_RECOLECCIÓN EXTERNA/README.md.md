# Recolección externa

Esta carpeta contiene el material para evaluadores externos.

## Archivos

- `Recoleccion_externa_template.csv`: plantilla vacía para registrar evaluaciones.
- `Recoleccion_externa_schema.json`: esquema de columnas y tipos.

## Cómo usarla

1. Enviar al evaluador el kit final: `06_kits/Kit_Evaluacion_STEV_v1.0.md`.
2. Pedir que complete una fila por ejercicio.
3. Usar `Recoleccion_externa_template.csv` como formato de entrega.
4. Validar el archivo contra `Recoleccion_externa_schema.json`.

## Privacidad

- No se publican prompts completos de evaluaciones externas sin anonimizar.
- No se publican evaluaciones de terceros sin consentimiento.
- Los datos derivados se publican anonimizados.

## Relación con otras carpetas

- `05_pilotos/etapa5/`: resultados finales.
- `00_cierre/DataAvailability_STEV.md`: condiciones de disponibilidad.
